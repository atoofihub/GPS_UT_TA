Comprehensive Melbourne–Wübbena and Cycle Slip Lesson

From first principles to multi-epoch numerical solutions and interactive experiments with real data from four GNSS constellations

Introduction: the problem we are solving

A GNSS receiver records two important observation types for each satellite. Code measures an approximate range and usually has more noise. Carrier phase is very precise, but it contains an integer ambiguity. If the receiver loses track of cycles for an instant, the phase jumps.

We call this sudden jump a cycle slip. This lesson shows how to build a testable two-frequency combination, move a time window across it, and separate a slip from ordinary variation.

What is a window?
A window is a short sequence of consecutive recent epochs. Instead of comparing the entire day with one fixed average, the detector estimates normal behavior from this local neighborhood. When the window moves, the statistical reference moves with the data.

Why do we build two combinations?

What is Melbourne–Wübbena?

Melbourne–Wübbena is a linear combination of two carrier phases and two codes on two frequencies. Its phase part is a phase difference and its code part is frequency-weighted. Common geometry, satellite-clock effects, and parts of the path error are largely smoothed in this structure. The result is well suited to detecting changes in the integer cycle count.

What is Geometry-Free?

The Geometry-Free combination uses only the two carrier phases. Geometry-dependent terms cancel in the difference, while the ionospheric effect remains. A cycle slip also creates a jump in GF, so it serves as a second witness for an MW event.

GF = λiLi − λjLj
MW = λW(Li − Lj) − (fiCi + fjCj)/(fi + fj)
What each one is used for
MW is used to detect integer phase jumps and estimate their cycle count. GF provides an independent event check and helps separate a real jump from code noise.

1. How is Melbourne–Wübbena formed?

Assume that two frequencies i and j are available for one satellite. First compute the wide-lane wavelength from their frequency difference.

λW = c / |fi − fj|

Compute the wide-lane phase in meters, the code combination, and MW as follows.

ΦW = λW(Li − Lj)
RN = (fiCi + fjCj)/(fi + fj)
MW = ΦW − RN
Why wide-lane?
Because the frequency difference is smaller than either carrier frequency, λW is larger. An integer phase change therefore appears as a more visible jump in MW.

5. Full theory and implementation layer for cycle-slip detection

This section starts with the physical definition of a phase jump and ends with the final decision, arc repair, and the effect on least squares. k is the epoch index, i,j are two frequencies, and λ is wavelength.

5.1 What exactly is a cycle slip?

With a healthy lock, the receiver tracks carrier phase continuously while the integer ambiguity stays constant. If tracking is lost for a few cycles, the integer changes by ΔN:

Nk = Nk−1 + ΔNk   ⇒   Φk = Φksmooth + ΔNkλ

A slip is therefore a sudden phase offset; satellite geometry does not create such a step over 30 seconds. For GPS L1, λ₁≈0.1902937 m, so three cycles equal 0.5709 m. Typical causes are blockage, severe multipath, low C/N₀, and rapid ionospheric changes.

5.3 Observation equations and parameter meaning

Pi = ρ + c(δtr−δts) + T + Ii + bP,i + εP,i
Φi = ρ + c(δtr−δts) + T − Ii + λiNi + bΦ,i + εΦ,i

ρ is geometric range, T tropospheric delay, Iᵢ ionospheric delay, Nᵢ integer ambiguity, and ε noise. Code and phase share range, clock, and troposphere, while ionosphere has opposite signs. That structure enables geometry-free combinations.

5.4 Geometry-free combination GF

GF = Φi − Φj = (λiNi−λjNj) + (Ii−Ij) + bias + noise
ΔGFk = GFk − GFk−1 ≈ λiΔNi − λjΔNj

Range, clocks, and troposphere cancel, so a fast GF change is strong slip evidence. GF remains sensitive to ionosphere. One L1 cycle gives about 0.1903 m. If ΔN₁=9 and ΔN₂=7, the near-cancellation produces only about 0.0033 m; GF is nearly blind.

5.5 Building the Melbourne–Wübbena combination

λW = c/(fi−fj)   ≈   0.8619 m (GPS L1/L2)
ΦW = (fiΦi−fjΦj)/(fi−fj)
PN = (fiPi+fjPj)/(fi+fj)
MW = ΦW − PN

Substitution cancels range, clocks, and troposphere. The ideal result is:

MW ≈ λW(Ni−Nj) + hardware bias + noise
ΔMWk ≈ λW(ΔNi−ΔNj)

MW is therefore very sensitive to unequal slips. Because code is included, it is noisier than raw phase. If both frequencies slip by exactly the same amount, ΔNᵢ=ΔNⱼ, MW may stay near zero and must be supported by GF or CMC.

5.7 MW_res, moving window, and robust statistics

Absolute MW contains a constant ambiguity and hardware bias; local changes are what detection needs. In this lesson the blue line is MW_res = MW − NWLλW. If a known teaching jump of n cycles is added, the red teaching line is:

MWred(k)=MWres(k)+λWΣj≤knj

The red line is not a second sensor measurement. It is the same blue path with a known offset, so students can see the arithmetic effect of a slip. Real detection must still be based on epoch differences and the raw observations.

W=[−0.02,0,0.02] m  →  median(W)=0
MAD=median(|W−median(W)|)=0.02
σ≈1.4826·MAD=0.0297 m
Z=|d−median|/σ

For d=0.88 m, Z≈29.7; with threshold K=6 it is flagged. Then compute n=round(d/λW) and test r=d−nλW. A practical condition such as |r|≤0.25λW, together with a reasonable maximum cycle count, rejects isolated outliers.

5.8 From combinations to per-frequency slip counts

MW gives a difference of two frequency slips, while GF provides a second weighted equation:

[ λW −λW ; λi −λj ] [ΔNi; ΔNj] = [ΔMW; ΔGF]

Solve this 2×2 system and round to the nearest integers. If the determinant is small, noise is high, or a field is missing, keep the result as suspect and use neighboring epochs, Doppler, or the next arc.

5.11 Kalman and RTK consequences

In a filter, a slip means the ambiguity state is no longer consistent with its previous value. If it is not reset, innovation grows, weighting becomes misleading, and RTK integer fixing can fail. Feed LLI, ΔMW, and ΔGF to quality control: reset the ambiguity, inflate its covariance, or temporarily exclude the satellite.

5.12 Single-frequency support: CMC and Doppler

CMCi=Φi−Pi   ⇒   ΔCMC≈λiΔNi + noise
ΔΦpred≈−(Dopplerk+Dopplerk−1)Δt/2
dk=Φk−Φk−1−ΔΦpred

CMC is noisier because of code, while Doppler depends on the receiver sign and unit convention. Both are valuable independent witnesses when GF or MW is unavailable.

5.14 Implementation caveats

  • A slip is cumulative: every later epoch carries the new offset.
  • The red teaching layer must be clearly labeled as derived; proof of detection comes from ΔMW/ΔGF and the raw observations.
  • MW is blind to equal slips; no single detector covers every case.
  • Normalize units before combining: phase in meters, code in meters, Doppler according to the receiver convention.
  • After a data gap, do not compare the first valid epoch with the last epoch of the previous arc; start a fresh arc.
